# 9-2. 프롬프트 설계 패턴(역할·예시·단계적 추론)

좋은 프롬프트는 즉흥적으로 쓰는 것이 아닙니다. 반복 검증된 패턴이 있습니다.

---

## 패턴 1: 역할 부여(Role Prompting)

모델에게 구체적인 페르소나를 부여하면 해당 역할의 관점에서 답변합니다.

```python
# 역할 없음
prompt = "이 코드를 리뷰해줘."

# 역할 있음
system = """당신은 10년 경력의 Java 백엔드 시니어 개발자입니다.
코드 리뷰 시 다음을 반드시 확인합니다:
1. 예외 처리 누락
2. 트랜잭션 경계
3. N+1 쿼리 문제
4. 보안 취약점

각 항목별로 문제가 있으면 구체적인 수정 방법을 제시하고,
문제가 없으면 "확인됨"이라고 명시합니다."""
```

역할 부여가 효과적인 이유: 모델의 훈련 데이터 중 해당 역할에 맞는 패턴을 활성화하기 때문입니다.

---

## 패턴 2: Few-Shot 예시

예시를 보여주면 원하는 형식과 품질을 직접 시연할 수 있습니다.

```python
prompt = """리뷰 텍스트를 읽고 감성(긍정/부정/중립)과 핵심 키워드를 추출하세요.

리뷰: "배송이 빠르고 포장이 깔끔했어요. 상품 품질도 기대 이상입니다."
감성: 긍정
키워드: 빠른배송, 깔끔한포장, 품질만족

리뷰: "상품은 괜찮은데 배송이 너무 오래 걸렸어요."
감성: 중립
키워드: 품질양호, 배송지연

리뷰: "{customer_review}"
감성:"""
```

예시 수에 따른 분류:
- **Zero-shot**: 예시 없이 지시만
- **One-shot**: 예시 1개
- **Few-shot**: 예시 2~5개 (보통 이 범위가 가장 효과적)

예시가 많다고 좋은 게 아닙니다. 토큰 소비가 늘고, 예시의 질이 출력 품질을 결정합니다.

---

## 패턴 3: Chain-of-Thought(단계적 추론)

복잡한 문제는 "단계별로 생각해봐"를 추가하면 정확도가 높아집니다.

```python
# 단계적 추론 없음
prompt = "A 창고에서 B 도시까지 최적 배송 경로는?"

# 단계적 추론 있음
prompt = """A 창고에서 B 도시까지 최적 배송 경로를 찾아야 합니다.

단계별로 생각해보세요:
1. 현재 알고 있는 정보를 정리하세요
2. 제약 조건을 나열하세요 (도로 상황, 시간, 비용)
3. 가능한 경로를 나열하세요
4. 각 경로를 제약 조건 기준으로 평가하세요
5. 최적 경로를 선택하고 이유를 설명하세요"""
```

수학 문제, 논리 추론, 복잡한 의사결정에서 효과가 큽니다.

## 패턴 4: 구조화된 지시

출력 형식을 명확히 지정합니다.

```python
prompt = """다음 고객 피드백을 분석하고 아래 형식으로 답하세요.

형식:
- 주요 불만: (한 문장)
- 감성 점수: (1~5, 1=매우 부정, 5=매우 긍정)
- 즉시 조치 필요: (예/아니오)
- 권장 대응: (한 문장)

피드백: "{feedback}"

분석:"""
```

---

## 패턴 5: 제약과 경계 설정

모델이 하면 안 되는 것을 명시합니다.

```python
system = """당신은 회사 HR 챗봇입니다.

답할 수 있는 것:
- 연차 사용 방법
- 복리후생 제도
- 사내 규정 조회

답하면 안 되는 것:
- 타 직원 정보
- 급여 관련 구체적 수치
- 회사 미공개 정보

위 범위를 벗어나는 질문은 "해당 내용은 HR팀에 직접 문의해 주세요."라고 안내하세요."""
```

## 패턴 결합: 실전 예시

여러 패턴을 결합해 실용적인 프롬프트를 만듭니다.

```python
system = """당신은 상품 설명 카피라이터입니다. 
쇼핑몰 상품 상세 페이지용 설명을 작성합니다.

작성 원칙:
- 구매 욕구를 자극하되 과장하지 않는다
- 핵심 특징 3가지를 먼저 배치한다
- 문장은 짧고 명확하게
- 이모지 사용 금지"""

user_prompt = """상품 정보:
- 이름: 에어팟 프로 2세대
- 가격: 359,000원
- 특징: ANC 노이즈 캔슬링, 공간 음향, 충전 케이스 MagSafe 지원

예시 출력 형식:
[핵심 3줄 요약]
① ...
② ...
③ ...

[상세 설명]
(2~3문단)

위 형식으로 상품 설명을 작성하세요."""
```

## 프롬프트 설계 원칙

| 원칙 | 나쁜 예 | 좋은 예 |
|------|--------|--------|
| 구체적으로 | "분석해줘" | "긍정/부정/중립으로 분류하고 근거를 한 문장으로 써줘" |
| 형식 지정 | 없음 | JSON, 표, 번호 목록 등 명시 |
| 길이 제한 | 없음 | "200자 이내로 요약해줘" |
| 예시 포함 | 없음 | 원하는 출력 예시 1~3개 |
| 역할 부여 | 없음 | "당신은 ... 전문가입니다" |

---

> 좋은 프롬프트는 처음에 나오지 않습니다. 작성하고, 테스트하고, 수정하는 반복이 필요합니다.
