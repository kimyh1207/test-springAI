# 9장. 프롬프트 설계와 Context

## 들어가며

LLM은 호출하는 방법에 따라 결과가 극단적으로 달라집니다. 같은 모델이라도 프롬프트를 어떻게 짜느냐에 따라 쓸모없는 답변과 정확한 답변의 차이가 납니다. 프롬프트 엔지니어링은 모델을 바꾸지 않고 출력을 통제하는 기술입니다.

- **[9-3. Context 관리와 구조화된 출력](./9-3-context-management.md)** — 긴 대화에서 컨텍스트를 유지하고, 파싱 가능한 형태로 받기

---

> 프롬프트는 모델에게 보내는 명세서입니다. 모호한 명세서는 모호한 결과를 낳습니다.

이 챕터를 마치면 LLM의 동작 방식을 이해하고, 목적에 맞는 프롬프트를 설계하고, 출력을 프로그램에서 안정적으로 활용할 수 있습니다.
