# 15장. RAG 파이프라인 설계 및 구축

## 들어가며

14장에서 임베딩과 Vector DB를 배웠습니다. 이 챕터에서는 그것을 연결해 완성된 RAG 파이프라인을 만듭니다. 문서를 적재하고, 쿼리를 처리하고, 답변을 생성하고, 환각을 줄이는 전 과정입니다.

RAG는 현재 기업에서 가장 많이 쓰이는 LLM 패턴입니다. 사내 문서 검색, 고객 지원 챗봇, 법률·의료 문서 Q&A 모두 이 구조 위에서 돌아갑니다.
