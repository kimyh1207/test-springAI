# 7장. 피처 엔지니어링

## 들어가며

모델의 성능은 알고리즘이 아니라 데이터가 결정합니다. 같은 모델이라도 피처를 어떻게 만드냐에 따라 정확도가 크게 달라집니다. 피처 엔지니어링은 원시 데이터를 모델이 학습할 수 있는 형태로 변환하는 과정입니다.

데이터 과학자가 실제 업무에서 가장 많은 시간을 쓰는 작업이기도 합니다.

> 피처 엔지니어링은 도메인 지식과 데이터 이해가 만나는 지점입니다. 수식보다 통찰이 먼저입니다.

이 챕터를 마치면 원시 데이터를 모델에 바로 투입할 수 있는 형태로 변환하고, 누수 없이 재현 가능한 파이프라인을 구성할 수 있습니다.
