# 16장. AI Agent 설계 및 구축

## 들어가며

RAG는 LLM에게 정보를 줍니다. 에이전트는 LLM에게 행동 능력을 줍니다. 검색하고, 계산하고, API를 호출하고, 결과를 보고 다음 행동을 결정합니다. 단순한 질답을 넘어 실제 작업을 수행하는 시스템입니다.
