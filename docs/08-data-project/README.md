# 8장. 데이터 분석 미니 프로젝트

## 들어가며

배운 것은 써봐야 내 것이 됩니다. 이 챕터는 실제 데이터를 가져와 분석 문제를 정의하고, 전처리하고, 인사이트를 도출하고, 그것을 서비스나 모델로 연결하는 전 과정을 처음부터 끝까지 직접 해보는 미니 프로젝트입니다.

분석을 "보여주는 것"이 아니라 "결정에 쓰이는 것"으로 만드는 것이 목표입니다.

> 분석은 질문에서 시작합니다. 좋은 질문이 좋은 분석을 만듭니다.

이 챕터를 마치면 데이터를 처음 받았을 때 막막함 없이 분석 계획을 세우고, 결과를 설득력 있게 전달할 수 있습니다.
