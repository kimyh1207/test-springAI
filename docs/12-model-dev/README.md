# 12장. 모델 개발 및 최적화

## 들어가며

모델을 만드는 것과 좋은 모델을 만드는 것은 다릅니다. 평가 지표를 올바르게 선택하고, 과적합을 통제하고, 하이퍼파라미터를 체계적으로 탐색하고, 실험을 기록해야 합니다. 이 챕터는 모델 개발의 반복 루프를 효율적으로 돌리는 방법을 다룹니다.

---

> 모델 개발은 한 번에 완성되지 않습니다. 실험 → 평가 → 수정의 반복입니다. 반복을 빠르게 돌릴수록 좋은 모델이 나옵니다.

이 챕터를 마치면 모델 성능을 올바르게 측정하고, 과적합 없이 최적화하고, 실험 결과를 체계적으로 관리할 수 있습니다.
