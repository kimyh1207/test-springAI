# 5장. 데이터 분석 개요와 기초 통계

## 들어가며

AI를 잘 만들려면 데이터를 읽을 수 있어야 합니다. 모델이 무엇을 학습했는지, 결과가 믿을 만한지, 어디서 틀렸는지. 이 모든 판단은 데이터를 이해하는 능력에서 나옵니다.

통계를 공식으로 외울 필요 없습니다. **데이터가 말하는 것을 듣는 방법**을 익히는 것이 목표입니다.
