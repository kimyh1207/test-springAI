# 4장. 웹 서비스 설계 미니 프로젝트

## 들어가며

배운 것은 써봐야 내 것이 됩니다. 2장과 3장에서 프론트엔드와 백엔드를 각각 배웠습니다. 이 챕터에서는 둘을 연결해 하나의 서비스를 만듭니다.

목표는 완성도가 아닙니다. **실제로 동작하는 것을 처음부터 끝까지 혼자 만들어보는 경험**입니다. 막히는 지점이 어디인지, 무엇을 더 공부해야 하는지는 만들어봐야 보입니다.
